# review-widget composition manifest — Marketing Hub prototype pages

Composed 2026-10-28. Operator: "Apply these same two pages to the staging. subdomain and the prototypes in the hub. i want
to send the prototype pages for review via the commenting widget", and, on scope: "Don't we have only two pages, i.e. the
same urls for these two pages across the landing page and microsite website?" So the widget sits on the main-site
prototypes only: `microsites/default/about.html` and `microsites/default/privacy-policy.html`. The other seven folders'
copies are the same staging page with the menu links pointing inside their microsite.

The source lives here because `build-microsites.mjs` deletes and rebuilds `public/marketing-hub/microsites/` on every run.

The hub app's own composition (`public/marketing-hub/review-mode.js`, MH-95) is built for hash-routed screens; these are
plain mirrored pages, so this copy takes the harassment-lp composition (pathname pages, assets loaded next to the
bootstrap, so `../_review/` works from a microsite folder).

## Deviations from the harassment-lp copy
1. **Stable page key.** `CFG.pageKey(location)` (one line added to `pageSlug()`): `credo-prototype:<file>`, e.g.
   `credo-prototype:about`. The pathname key would differ between localhost and the GitHub Pages mirror.
2. **"All pages" = prototype pages only.** `CFG.pageFilter(page)` (one condition added where `all` is built) keeps records
   whose page starts with `credo-prototype:`; the other Credo hubs share the `/comments` database.
3. **CSP.** The mirror's Content-Security-Policy (`tools/marketing-hub/mirror.mjs`) blocks every outside host; on the two
   reviewed pages only, `build-microsites.mjs` adds `https://www.gstatic.com` (Firebase SDK) to script-src and
   `https://*.firebaseio.com wss://*.firebaseio.com` to connect-src. Tracking and chat stay removed.
4. Unused here and left as is: the harassment-lp LIVE_MAP (live-page chip; no match for these files), variant anchors.

The records keep harassment-lp's shape, including a short `text_preview` of the commented element. These pages are
public copies of staging.credolegal.com pages, unlike the hub screens (MH-95 stores no preview there).

## Use
Reviewer link: `<hub mirror>/microsites/default/about.html?review=1` (and `privacy-policy.html?review=1`). Without
`?review=1` the page shows one floating "Comments" button and loads nothing else.
